# RaceDay - Event Management System

## System Description
RaceDay is a platform for managing road running and cycling events in South Africa.

## User Roles
- **Organiser**: Can create, edit, delete events, manage categories, and capture results.
- **Participant**: Can browse events, enrol in events, and view personal results.

## Setup Instructions
1. Clone this repository.
2. Run the `raceday-schema.sql` script in SQL Server Management Studio (SSMS) to create the database and sample data.
